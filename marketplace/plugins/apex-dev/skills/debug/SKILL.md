# Debug a failure

Start from the actual error, expected behavior and smallest reproducible trigger. Read relevant code and logs. Form a falsifiable explanation, then verify it before editing. Apply the smallest coherent fix, run meaningful checks and report remaining uncertainty. Preserve failure evidence. Do not retry ambiguous paid requests or weaken validation to make a check green.
