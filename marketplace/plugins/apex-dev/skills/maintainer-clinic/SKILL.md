description: Guide one consented maintainer clinic with one issue, bounded work and actual acceptance evidence.
disable-model-invocation: true
---
Inspect the selected issue and project contribution instructions in Plan. Confirm that the maintainer and contributor agreed to participate. Use /clinic for the human's local tracking record; do not contact projects or create issues/PRs automatically. Agree scope, recipient, files, acceptance evidence, reviewer and finite budget through the existing task workflow. Build requires the user to switch modes and approve actions. Preserve reproduction/test receipts and distinguish them from model claims. Present the patch for human review. A maintainer acceptance link and user observation are recorded separately; do not call work accepted merely because tests passed. Invite optional feedback and a second use without promising adoption, sponsorship or stars. Publish nothing without explicit authorization.
